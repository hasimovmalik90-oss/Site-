# Правила для КП (коммерческих предложений)

- Стоимость указываем только общей суммой (общий чек за период). Не разбиваем цену по направлениям или исполнителям (например, «стратегия 120 000 / производство 130 000»).
- Страница КП и её презентация (`<папка>/slides/`) всегда правятся вместе, чтобы не расходились.
